## LLM Module

This repository provides an autonomous autoregressive language model implementation under `llm`.

### Features

- Discrete whitespace and punctuation tokenizer with `<pad>`, `<unk>`, `<bos>`, and `<eos>` tokens.
- N-gram conditioned language model with Laplace smoothing.
- Configurable sampling controls: temperature scaling, top-k filtering, and repetition penalty.
- Perplexity evaluation metrics.

### Running Tests

Execute the unit test suite:

```bash
python3 -m unittest discover tests
```
